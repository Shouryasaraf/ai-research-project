# Exploratory stateful trace replay (2026-10-10)

This is a **modeled offline counterfactual**, not a vFW traffic experiment, a
measured throughput result, or a confirmatory comparison. It uses the original
leakage-safe one-step forecast records and the unchanged
`synthetic_small.json` scenario. The new replay keeps a separate current
placement, target readiness, and two-slot cooldown for every model/policy.
PREWARM and SYNC each use an observation slot. An executed COMMIT changes the
modeled placement once; subsequent decisions exclude the current node. This
corrects the earlier interpretation risk of counting repeated independent
COMMIT *recommendations* as repeated migrations.

For the fixed `ewma_conformal` model, the descriptive outcomes were:

| Traffic segment | Policy | Simulated migrations | Warm / sync actions | Modeled excess demand (Mbps-seconds) | Modeled action cost (scenario utility units) |
|---|---|---:|---:|---:|---:|
| MAWI 2000 | Static | 0 | 0 / 0 | 12.722704 | 0 |
| MAWI 2000 | Reactive | 1 | 0 / 0 | 0 | 0.20 |
| MAWI 2000 | Full | 0 | 1 / 0 | 12.722704 | 0.05 |
| MAWI 2005 | Static | 0 | 0 / 0 | 0.010768 | 0 |
| MAWI 2005 | Reactive | 1 | 0 / 0 | 0 | 0.20 |
| MAWI 2005 | Full | 1 | 1 / 1 | 0 | 0.30 |
| Cyber4OT normal 003 | Static | 0 | 0 / 0 | 0.014464 | 0 |
| Cyber4OT normal 003 | Reactive | 1 | 0 / 0 | 0 | 0.20 |
| Cyber4OT normal 003 | Full | 1 | 1 / 1 | 0 | 0.30 |

The MAWI 2000 full-controller result is a negative result: uncertainty gating
prewarmed but did not synchronize/commit in this held-out segment. On the other
two, both reactive and full eliminate a very small modeled capacity excess,
while full incurs extra modeled actions. These results **do not support a
superiority claim**. Cyber4OT 003 was already used in the live transfer pilot;
this replay is exploratory and is not an independent confirmation.

Assumptions are part of the output JSON. In particular, training-derived
source capacity is hypothetical, targets and their carbon/risk/load values are
fixed modeled candidates, a commit takes effect optimistically in the same
slot, and capacity-limited served traffic is a mathematical cap rather than
observed goodput. Action costs are scenario utility terms, not measured money,
energy, emissions, packet loss, or interruption. The source is not a return
candidate. Readiness is a simple two-stage model, not conntrack-state proof.

`configs/scenarios/synthetic_small.json`, `--cooldown-slots 2`, and a *new*
