# Publication claim ledger

This ledger defines what can be written today, and what remains an open research gate. It is not a publication-readiness certificate.

| Claim | Current evidence | Allowed wording | Remaining gate |
|---|---|---|---|
| Controller implementation | Typed decisions, unit tests, sustained isolated traffic, six bounded proxy lifecycle repetitions | Implemented research prototype with a functional proxy lifecycle witness | General production lifecycle and cross-backend integration |
| Stateful continuity | Supported tuple checks, same-socket continuation and verified paired endpoint captures | Bounded application continuity with observed packet deficits | Sequence/window consistency, broader racing-update cases and exact service-outage definition |
| Restart safety | Supervised migration-process exit with three original flows resumed after reverse sync; target-state deletion remains blocked | Bounded active-flow failback when target state survives; fail-closed behavior otherwise | Unsupervised detection, full host/namespace failure and general state-loss recovery |
| Prediction advantage | Synthetic and historical-trace pilots | Mixed/negative comparative evidence | Independent, adequately repeated confirmatory evaluation |
| Carbon/risk placement | Modeled candidate grid and hard constraints | Modeled decision sensitivity | Calibrated provenance, multi-target traffic outcomes and estimated-emissions uncertainty |
| Adaptive threshold | Auditable formula, tests, fixed/adaptive grid | Context changes modeled decisions | Calibrated coefficients, horizon/history semantics and temporal anti-thrashing comparison |
| Novelty | Partial primary-source matrix and bibliography | Proposed integration contribution | Full-text and citation-chain review plus independent assessment |
| Reproducibility | Source snapshots in new batches, raw hashes, generated summaries, instructions | Locally reproducible artifact pipeline | Independent clean-host execution, artifact redistribution terms and remote CI |

## Decisions that need the owner

- Code license: not selected automatically. The private repository may remain unlicensed; public artifact distribution needs an explicit choice.
- Dataset redistribution: original MAWI captures are not part of the deliverable; permitted access and redistribution must be checked for any released source data.
- Submission venue and author list: not selected by the implementation agent. Venue scope and author consent are external to code correctness.

## Evaluation rules

Do not turn development pilots into confirmatory results by renaming folders. Freeze new hypotheses, primary endpoints, effect margins, repetitions, exclusions and stopping rules before collecting an independent final batch. Preserve the original negative results. A publishable contribution may be a careful characterization of when uncertainty gating helps or hurts; it need not claim universal performance improvement.
