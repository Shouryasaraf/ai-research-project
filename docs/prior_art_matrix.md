# Working Prior-Art Matrix

## Working positioning, not a novelty claim

The testable contribution is the **specific integration and ordering** of calibrated traffic uncertainty, feasible carbon/security placement, warm-up/state checks, an adaptive decision threshold, and a fail-closed fallback in a stateful vFW controller. Deng et al. are particularly direct prior art for safe vFW elasticity; our present lab does **not** reproduce their full policy dependency, buffering, distributed forwarding or scaling analysis. Whether the exact remaining integration is absent from prior work remains unresolved until full-text and citation-chain review. Experiments must isolate each component with matched baselines and report trade-offs, including failures. Current code demonstrates both source-pinned proxy transitions and bounded same-socket TCP continuation after namespace route changes with coarse conntrack copying. This is not full TCP-state equivalence or an atomic transition guarantee. See `novelty_positioning.md` for the additional OpenNF comparison and claim limits.
